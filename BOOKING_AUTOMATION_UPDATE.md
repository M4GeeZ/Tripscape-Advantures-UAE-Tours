# Booking automation update

- Primary booking submit CTA is now **Book Enquiry Now**.
- Booking team email is `info@tripscapeadventures.com`.
- Booking team WhatsApp/call number is `+971 54 993 0684`.
- Company and customer both receive booking email confirmation.
- Customer email is taken from the submitted form.
- Full phone number includes the selected mandatory country code.
- If the customer does not have WhatsApp, no WhatsApp window is opened and the booking completes by email.
- If the customer has WhatsApp, a pre-filled enquiry opens to the Tripscape WhatsApp number after the backend accepts the booking.
- Optional Meta WhatsApp Cloud API support is included for an automatic confirmation to the customer's WhatsApp number when credentials + an approved template are configured.
- Campaign landing booking forms and Desert E-Jet booking form now use the same backend booking confirmation flow.
