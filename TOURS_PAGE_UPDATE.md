# Tours Navigation & Page Update

- Tours navbar item now opens a premium image mega-menu on desktop hover/focus.
- The arrow beside Tours rotates up/down to show the menu state.
- The mega-menu contains eight experience categories and direct category links.
- `/tours` now renders a complete searchable/filterable tours catalogue.
- `All` is selected by default.
- Tour cards include pointer-responsive 3D tilt, image zoom, glow and layered shadows.
- New code follows the component-folder architecture:
  - `components/ToursMegaMenu/`
  - `components/TourCard/`
  - `pages/Tours/`
  - `pages/Home/`
